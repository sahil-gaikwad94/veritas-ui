## Core Decorator & Class

| Symbol | Type | Description |
| :--- | :--- | :--- |
| `verified_schema` | decorator | Mark a function as a Vexx-verified schema |
| `VerifiedSchema` | class | Base class for verified schemas |

### `verified_schema`

Transforms a Python function into a verified schema that enforces constraints during LLM token decoding.

<CodeBlock language="python" code={`from vexx import verified_schema

@verified_schema
def my_schema(p: Portfolio):
    require(sum(p.weights.values()) == 1.0)`} copyable />

### `VerifiedSchema`

The underlying class. Use the decorator syntax for 99% of cases; use the class directly for programmatic schema construction.

<CodeBlock language="python" code={`from vexx import VerifiedSchema

# the decorator is VerifiedSchema(func, **config); config is the engine, not the constraints
schema = VerifiedSchema(
    my_func,
    solver="auto",            # auto | nano | z3
    reasoning_mode="crane_cot",  # crane_cot | strict
    backtrack="cdcl_domain_cut",  # cdcl_domain_cut | none
    preflight_check=True,
)`} copyable />

## Four Constraint Verbs

| Symbol | Type | Description |
| :--- | :--- | :--- |
| `require` | function | Hard invariant — must hold for all valid instances |
| `derive` | function | Zero-DoF deterministic derivation — computed by Vexx |
| `prefer` | function | Soft preference — guides without causing hard failure (`weight`, `tag`) |
| `forall` | function | Universal quantifier over collections |

### `require(expr, tol=1e-6)`

Hard invariant enforced via Tier-1 HC4/AF2 contractors and Tier-2 NanoSolver.

<CodeBlock language="python" code={`from vexx import require

require(sum(p.weights.values()) == 1.0, tol=1e-6)
require(forall(p.weights.values(), lambda w: (0.05 <= w) & (w <= 0.50)))`} copyable />

### `derive(target == expr, tol=1e-6)`

Zero-DoF deterministic computation. Vexx computes `target` from `expr` — the LLM never samples it.

<CodeBlock language="python" code={`from vexx import derive, dot

derive(p.expected_return == dot(p.weights, RETURNS))`} copyable />

### `prefer(expr, weight=1.0, tag=None)`

Soft preference via Weighted MaxSMT. Guides token selection without causing hard failures.

<CodeBlock language="python" code={`from vexx import prefer

prefer(p.volatility <= 0.20, weight=0.8, tag="low_volatility")`} copyable />

### `forall(collection, lambda x: ...)`

Universal quantifier over dynamic collections, lowered into `ResidualAccumulator` bounds.

<CodeBlock language="python" code={`from vexx import forall

require(forall(p.weights.values(), lambda w: (0.05 <= w) & (w <= 0.50)))`} copyable />

## Mathematical Primitives

| Symbol | Type | Description | Complexity |
| :--- | :--- | :--- | :--- |
| `sum` | function | Symbolic summation | $O(n)$ |
| `dot` | function | Inner product over dictionaries | $O(n)$ |
| `quad_form` | function | Quadratic form $w^T \Sigma w$ | $O(n^2)$ |
| `sqrt` | function | Square root with sign-aware lifting | $O(1)$ |
| `keys_subset` | function | Set-inclusion constraint over keys | $O(k)$ |

### Examples

<CodeBlock language="python" code={`from vexx import sum, dot, quad_form, sqrt, keys_subset

require(sum(p.weights.values()) == 1.0, tol=1e-6)
derive(p.expected_return == dot(p.weights, RETURNS))
require(quad_form(p.weights, COV) <= 0.04)
require(sqrt(p.variance) <= 0.20)
require(keys_subset(p.weights, {"AAPL", "MSFT", "NVDA"}))`} copyable />

## Engine Functions

| Symbol | Type | Description |
| :--- | :--- | :--- |
| `run_preflight` | function | 0-token feasibility check over a compiled `VirSpec` |
| `generate` | function | Constrained decoding through a model adapter |
| `verify_instance` | function | Verify a single instance |
| `verify_json` | function | Verify a JSON document |
| `synth` | function | Schema synthesis from JSON |
| `analyze_containers` | function | Analyze container usage |

### `run_preflight(spec)` / `schema.preflight`

Pre-flight runs automatically when a `@verified_schema` module is imported (`preflight_check=True`). The
result is kept on the object, and `run_preflight` re-runs it against a compiled `VirSpec`:

<CodeBlock language="python" code={`from vexx import run_preflight

report = my_schema.preflight             # computed at import time
print(report.status)                     # 'SAT' | 'UNKNOWN' | 'UNSAT'
print(report.is_sat)                     # True only for a checked witness
print(report.details)                    # why it is UNKNOWN, when it is

fresh = run_preflight(my_schema.spec)    # re-run against the compiled spec
assert fresh.status == report.status`} copyable />

`UNSAT` never reaches you as a report: the decorator raises `InfeasibleSpecError` at import, with
`.conflicts` and a `.relaxation` dict of hints.

### `generate(model, prompt, spec, ...)`

Decode through any object with `next_logits(prefix_text) -> Mapping[str, float]`. `vexx.testing`
ships deterministic models; `vexx.bridges` adapts real tokenizers.

<CodeBlock language="python" code={`import vexx as vx
from vexx.testing import StructuredReasoningModel

result = vx.generate(
    model=StructuredReasoningModel(),     # or a bridge adapter
    prompt="propose a portfolio",
    spec=my_schema,
    temperature=0.0,
    return_proof=True,                    # attach a certificate on PASS
)
print(result.raw)                         # exact JSON that was decoded
print(result.value)                       # validated value
print(result.report.status)               # PASS before the caller sees it`} copyable />

There is no `vx.decode()` function: `vexx.decode` is the module that implements `generate` and
`VexxSession`.

### `synth(samples, ...)`

Auto-generate `@verified_schema` from sample JSON.

<CodeBlock language="python" code={`from vexx import synth

schema_code = synth(samples=[{"a": 1.0}, {"a": 2.0}])
print(schema_code)`} copyable />

## Engine entry points (importable)

| Symbol | Type | Description |
| :--- | :--- | :--- |
| `doctor` | function | Engine diagnostics: `{'version', 'python', 'engine', 'wire_version'}` |
| `check_spec(spec)` | function | Pre-flight result for a compiled spec |
| `verify(spec, instance)` | function | Instance verification |
| `verify_proof(certificate, expected_spec=None)` | function | Offline certificate check |
| `synth(samples=None, ...)` | function | Schema synthesis from JSON examples |
| `build_certificate(spec, instance)` | function | Seal a proof certificate |

The shell equivalents (`check-spec`, `verify`, `verify-proof`, `inspect`, `doctor`, `synth`) live in
`vexx.cli.main`; `inspect` is **only** a subcommand — there is no importable `vx.inspect`.

## Modules

| Module | Description |
| :--- | :--- |
| `vexx.cartridges` | Domain cartridges (quant, sql, sec, etc.) |
| `vexx.bridges` | Runtime bridges (vLLM, SGLang, llama.cpp, etc.) |
| `vexx.rl` | RL trajectory collector |
| `vexx.ltlf` | LTLf temporal logic |
| `vexx.cli` | CLI entry points |

<Callout variant="info" title="One import surface">

The top-level package exports the authoring DSL, verification, engine primitives, certificates, LTLf helpers and the RL collector. Bridges and cartridges live in their own namespaces:

```python
from vexx import verified_schema, require, derive
from vexx.cartridges import quant, sql
from vexx.bridges import patch_vllm, VexxVLLMBridge
```
</Callout>
