# Rust PyO3 Native API

Reference for `veritas._native` — the PyO3 bindings from `crates/veritas-py`. These are the low-level functions that power the Python API.

---

## `PdaHandle`

The `PdaHandle` is the main interface to the JSON Pushdown Automaton. Created once per decode, fed tokens one at a time.

### Method Reference

| Method | Signature | Description |
| :--- | :--- | :--- |
| `new` | `(seed: str) -> PdaHandle` | Create a new PDA handle with initial seed text |
| `push` | `(token: str) -> bool` | Feed a token into the PDA; returns False if invalid |
| `is_alive` | `() -> bool` | PDA still in a valid state |
| `is_complete` | `() -> bool` | JSON document is syntactically complete |
| `accepts` | `(token: str) -> bool` | Check if a token is valid without pushing it |
| `depth` | `() -> int` | Current stack nesting depth |
| `last_event` | `() -> str` | Description of the last PDA transition |
| `candidates` | `() -> List[str]` | Top candidate next tokens (for UI display) |
| `mask` | `() -> List[float]` | Full logit mask tensor (0.0 = valid, -inf = invalid) |
| `clone_handle` | `() -> PdaHandle` | Deep copy for speculative decoding |

### Example Usage

<CodeBlock language="python" code="from veritas._native import PdaHandle

# Create PDA starting with an open brace
handle = PdaHandle.new("{")

# Feed tokens one at a time
tokens = ['"', 'w', 'e', 'i', 'g', 'h', 't', 's', '"', ':']
for token in tokens:
    if not handle.push(token):
        print(f"Rejected token: {token}")
        break

# Check state
print(handle.depth())        # 1
print(handle.is_alive())     # True
print(handle.accepts('"'))   # True — can start a string value
print(handle.accepts('}'))   # False — can't close without value

# Get logit mask for LLM
mask = handle.mask()  # List[float]: 0.0 for valid, -inf for invalid

# Clone for speculative decoding
handle_copy = handle.clone_handle()`} copyable />

## Top-Level Functions

| Function | Signature | Description |
| :--- | :--- | :--- |
| `prefix_status` | `(text: str) -> dict` | PDA status for a token prefix |
| `validate_document` | `(text: str) -> bool` | Validate a complete JSON document |
| `canonical_document` | `(text: str) -> str` | Canonical JSON form |
| `document_value` | `(text: str) -> Any` | Extract document value |
| `allowed_tokens` | `(text: str) -> List[str]` | Allowed next tokens |
| `numeric_prefix` | `(prefix: str) -> dict` | `[lo, hi, valid]` interval bounds |
| `contract` | `(spec_json: str) -> str` | Run interval contraction |
| `log_volume` | `(spec_json: str) -> float` | Log volume of feasible region |
| `solve_linear` | `(spec_json: str) -> dict` | Solve linear constraints |
| `solve_linear_exact` | `(spec_json: str) -> dict` | Exact linear solution |
| `engine_info` | `() -> dict` | Engine version & metadata |
