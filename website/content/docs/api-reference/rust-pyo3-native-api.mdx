There is no separate native API to learn: the accelerator sits behind the same Python objects. The
`veritas.native` module reports whether it is loaded and exposes the low-level calls used underneath.

<Callout variant="info" title="Reference first">
Every function below falls back to pure Python when the compiled extension is missing. The extension is
`veritas_py` (PyO3, `abi3`); the public Python import stays `veritas`.
</Callout>

## Availability

<CodeBlock language="python" title="what is actually loaded" code={`import veritas.native as native

print(native.available())        # False without the extension
print(native.info())
# {'name': 'python', 'version': 'pure', 'wire_version': None,
#  'native_available': False, 'load_error': "ModuleNotFoundError: No module named 'veritas_py'"}

print(native.disabled_by_env())  # True when VERITAS_NO_NATIVE is set
print(native.wire_version())     # None, or the native wire protocol version
print(native.load_error())       # import error text, or None`} copyable />

## Primitives

<CodeBlock language="python" title="status, mask, interval" code={`import veritas.native as native
from veritas import Interval

print(native.prefix_status('{"a":'))    # 'incomplete'
print(native.prefix_status('{"a":1}'))  # 'complete'
print(native.prefix_status('}'))        # 'invalid'

vocabulary = ['{', '}', '"a"', '1', '2']
print(native.mask('{"a":', vocabulary)) # [True, False, True, True, True]

# native returns None when it cannot answer; the wrapper falls back
print(native.mask_or_none('{"a":', vocabulary))
print(native.numeric_prefix('0.2', (0.0, 1.0)))   # Interval(0.2, 0.3)
print(native.numeric_prefix_or_none('0.2', (0.0, 1.0)))  # None without native

print(native.canonical_document('{"b":1,"a":2}'))  # '{"b": 1, "a": 2}'`} copyable />

## Higher-level objects

The classes you normally touch are exported from `veritas` itself — importing them does **not** require
the extension:

| Object | Purpose |
| :--- | :--- |
| `Interval`, `AffineForm`, `Hc4AffineContractor`, `ResidualAccumulator` | Tier 1 numerics |
| `JSONPushdownAutomaton`, `TokenMasker` | Tier 0 grammar and exact masks |
| `TokenHealer`, `JumpForwardPrefill`, `ByteTokenizer`, `TokenizerProtocol` | Jump-forward token boundaries |
| `VeritasNanoSolver`, `SolverStatus` | Tier 2 linear search |
| `CdclJumpbackEngine`, `TabuPrefixTrie`, `ConflictBranchRecord` | Backtracking |
| `CraneModeController`, `ShadowParser` | Reasoning and structural shadow state |
| `ZeroDofEngine` | Ready-field derivation |
| `ProofCertificate`, `build_certificate`, `verify_proof` | Certificates |

```python
from veritas import Interval, TokenMasker, TokenHealer, VeritasNanoSolver

span = Interval.from_numeric_prefix("0.4", (0.05, 0.5))
masker = TokenMasker(['{', '}', '"a"', '1'])
masker.valid_mask('{"a":')
```

## Kill switch

<CodeBlock language="bash" title="A/B the accelerator" code={`VERITAS_NO_NATIVE=1 python -m pytest tests/test_native_backend.py -q
VERITAS_NO_NATIVE=1 python benchmarks/native_speedup.py`} copyable />

The switch is read **per call**, so a long-running process can flip it without reinstalling.

## Crates

| Crate | Contents |
| :--- | :--- |
| `veritas-core` | Dependency-free ports: intervals, JSON automaton, tri-state evaluator, HC4, exact solver, CRANE, CDCL, 0-DoF, healing, SMT-LIB emission |
| `veritas-py` | PyO3 `abi3` bindings exposed as `veritas_py` |
| `veritas-wasm` | `wasm32-unknown-unknown` build for browser use |

CI runs `cargo test -p veritas-core --all-targets`, `cargo clippy -D warnings`, the PyO3 build and the wasm
build. `tests/test_native_backend.py` pins parity with Python; a native disagreement falls back.

<Callout variant="warn" title="No native = no speedup, not no verification">
Numbers such as 4.07 ms → 0.23 ms belong to a specific runner and vocabulary. Reproduce them with
`benchmarks/native_speedup.py`; never quote a headline as a guarantee for your hardware. Without the
extension, everything still verifies — only the per-token cost changes.
</Callout>
