`crates/veritas-wasm` compiles the grammar and numeric primitives for `wasm32-unknown-unknown`. It is
built for local tooling — a schema playground, a formatter, a mask preview — not as a replacement for
server-side decoding.

<Callout variant="warn" title="Not published to npm">
There is no `veritas-wasm` package on the registry. Build the crate and vendor the generated `pkg/`
directory, or serve the `.wasm` yourself. The import path in the examples assumes that local bundle.
</Callout>

## `PdaHandle`

```typescript
class PdaHandle {
  constructor();
  push(text: string): boolean;
  isAlive(): boolean;
  isComplete(): boolean;
  accepts(): boolean;
  depth(): number;
  maskJson(vocabularyJson: string, eos: string): string;
}
```

`maskJson` returns a **JSON array of allowed token indices**, or `{"status":"error","reason":"…"}` when
the vocabulary is malformed. It is not a `Float32Array` and there is no `cloneHandle` in the wasm build.

## Example

<CodeBlock language="typescript" title="validate and mask in the browser" code={`import init, {
  version,
  prefix_status,
  is_valid_document,
  canonical_document,
  numeric_prefix,
  PdaHandle,
} from './pkg/veritas_wasm';

await init();

console.log(version());

const handle = new PdaHandle();
handle.push('{"w');
console.log(handle.depth());       // 1
console.log(handle.isAlive());     // true
console.log(handle.accepts());     // true — can still complete

const allowed = JSON.parse(
  handle.maskJson(JSON.stringify(['"a"', '1', '}', '']), ''),
) as number[];
console.log(allowed);              // indices of valid next tokens

console.log(prefix_status('{"w'));            // 'incomplete'
console.log(is_valid_document('{"a": 1}'));   // true
console.log(canonical_document('{ "a" : 1 }')); // '{"a": 1}'
console.log(numeric_prefix('0.2', 0, 1, false)); // Float64Array [0.2, 0.3]`} copyable />

## In a worker

A worker keeps parsing off the main thread. Load the module inside the worker and expose a small message
protocol:

<CodeBlock language="typescript" title="veritas.worker.ts" code={`import init, { prefix_status, is_valid_document } from './pkg/veritas_wasm';

let ready: Promise<unknown>;

self.onmessage = async (event: MessageEvent) => {
  const { id, method, args } = event.data ?? {};
  ready ??= init();
  await ready;
  try {
    const result =
      method === 'prefix_status' ? prefix_status(args[0])
      : method === 'is_valid_document' ? is_valid_document(args[0])
      : null;
    (self as unknown as Worker).postMessage({ id, result });
  } catch (error) {
    (self as unknown as Worker).postMessage({ id, error: String(error) });
  }
};`} copyable />

<CodeBlock language="typescript" title="main thread" code={`const worker = new Worker(new URL('./veritas.worker.ts', import.meta.url), { type: 'module' });

function call<T>(method: string, ...args: unknown[]): Promise<T> {
  return new Promise((resolve, reject) => {
    const id = crypto.randomUUID();
    const onMessage = (event: MessageEvent) => {
      if (event.data?.id !== id) return;
      worker.removeEventListener('message', onMessage);
      event.data.error ? reject(new Error(event.data.error)) : resolve(event.data.result);
    };
    worker.addEventListener('message', onMessage);
    worker.postMessage({ id, method, args });
  });
}`} copyable />

## Scope

- Grammar, validity, canonicalisation and numeric prefix only.
- No schema compilation, no solver, no instance verification, no certificates.
- Error paths return a JSON string (`{status:"error"}`) rather than throwing panics across the boundary.
- The numeric prefix result is an interval of reachable values, not a rounded number.
