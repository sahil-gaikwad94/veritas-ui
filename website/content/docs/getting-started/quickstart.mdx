This page goes from an empty file to a verified portfolio. If you have not installed Vexx yet, start
with [Installation](/docs/getting-started/installation).

## The scenario

An assistant proposes portfolio weights. You need four guarantees:

1. the weights cover exactly the declared assets;
2. they sum to **1.0** (fully invested);
3. every weight is between **5%** and **50%**;
4. expected return, volatility and Sharpe are **computed from the weights**, never guessed.

The last point is what separates a verified schema from a JSON schema.

## Step 1 — write the schema

Create `portfolio_spec.py`:

<CodeBlock language="python" filename="portfolio_spec.py" code={`import vexx as vx
from pydantic import BaseModel

RETURNS = {"AAPL": 0.14, "MSFT": 0.13, "NVDA": 0.24}
RISK_FREE = 0.04
COV = {
    ("AAPL", "AAPL"): 0.048,
    ("AAPL", "MSFT"): 0.031,
    ("AAPL", "NVDA"): 0.042,
    ("MSFT", "MSFT"): 0.039,
    ("MSFT", "NVDA"): 0.036,
    ("NVDA", "NVDA"): 0.095,
}

class Portfolio(BaseModel):
    weights: dict
    expected_return: float
    volatility: float
    sharpe: float

@vx.verified_schema()
def portfolio(p: Portfolio):
    # structural + algebraic invariants
    vx.require(vx.keys_subset(p.weights, {"AAPL", "MSFT", "NVDA"}))
    vx.require(vx.sum(p.weights.values()) == 1.0, tol=1e-6)
    vx.require(vx.forall(p.weights.values(), lambda w: (0.05 <= w) & (w <= 0.50)))

    # zero degrees of freedom -> computed and spliced, never sampled
    vx.derive(p.expected_return == vx.dot(p.weights, RETURNS), tol=1e-5)
    vx.derive(p.volatility == vx.sqrt(vx.quad_form(p.weights, COV)), tol=1e-5)
    vx.derive(p.sharpe == (p.expected_return - RISK_FREE) / p.volatility, tol=1e-5)

    # quality threshold on a derived field
    vx.require(p.sharpe >= 0.55)`} copyable />

<Callout variant="info" title="Importing the schema">
The module compiles the schema at import time. Compilation includes preflight, so an impossible spec
raises `vx.InfeasibleSpecError` immediately — before any model or GPU is touched.
</Callout>

### What each verb means

| Call | Meaning |
| :--- | :--- |
| `require(expr, tol=…)` | Hard invariant. Every valid instance must satisfy it. |
| `derive(target == expr, tol=…)` | A deterministic equality. The field is computed once its inputs are known. |
| `prefer(expr, weight=…)` | Soft preference used to steer decoding; never overrides a hard constraint. |
| `forall(iterable, predicate)` | Universal quantifier over a dynamic container. |

## Step 2 — verify a concrete instance

<CodeBlock language="python" title="check the arithmetic yourself" code={`report = portfolio.verify({
    "weights": {"AAPL": 0.40, "MSFT": 0.35, "NVDA": 0.25}
})

print(report.status)      # PASS | FAIL | INCOMPLETE
print(report.values)      # {
                          #   'weights': {...},
                          #   'expected_return': 0.1615,
                          #   'volatility': 0.2044,
                          #   'sharpe': 0.5945
                          # }
print(report.spec_digest) # stable hash of the compiled specification`} copyable />

You passed only the weights. The derived fields were filled because they are fully determined by the
inputs. That is the same machinery the decoder uses, which is why passing `verify` means the decode
would have accepted the object too.

<Callout variant="check" title="Statuses are not optimistic">
`PASS` means every constraint was evaluated and satisfied. `FAIL` includes violated constraints,
residuals, a minimal unsat core and relaxation hints. `INCOMPLETE` means something could not be
evaluated — and is never treated as a pass.
</Callout>

## Step 3 — run preflight from the CLI

<CodeBlock language="bash" title="0-token feasibility check" code={`python -m vexx check-spec portfolio_spec.py

# schema: portfolio  (UNKNOWN)
#   fields:   weights, expected_return, volatility, sharpe
#   derived:  expected_return, volatility, sharpe
#   requires: 4  derives: 3
#   digest:   8578b89ceb5e41bef703919daf8242338cb963442908cecdb24e0475e96d28c0`} copyable />

`UNKNOWN` is the honest verdict for a schema built on a dynamic `dict` container: preflight proved the
arithmetic, but it could not *construct* a witness for `weights`, and the tool never reports `SAT` on a
witness it did not check. It is not a failure — `verify` still decides every instance, and `SAT` appears
as soon as a witness is constructible (try a schema of plain scalars). A genuinely contradictory spec is
different: it fails loudly and immediately.

Now tighten the spec until it is impossible — for example, demand that a window ends at or after 8 and
at or before 3:

<CodeBlock language="bash" title="infeasible spec, exit 2" code={`$ python -m vexx check-spec window_spec.py
error: InfeasibleSpecError: Spec window is infeasible at pre-flight
# exit code 2 · no model, no tokens, no decode`} copyable />

## Step 4 — decode with a model

The engine is model-agnostic: a model only needs a method that returns next-token logits for a prefix.

<CodeBlock language="python" title="solver-guided generation" code={`from vexx.testing import StructuredReasoningModel

model = StructuredReasoningModel()          # deterministic mock for a first run
result = vx.generate(model=model, prompt="propose a portfolio", spec=portfolio)

print(result.raw)          # the exact JSON stream that was decoded
print(result.value)        # validated model (or values dict)
print(result.report.status) # verified before the result is returned`} copyable />

Swap the mock for a real adapter when you are ready:

<CodeBlock language="python" title="real runtimes" code={`# Hugging Face: a logits processor you pass to generate()
from vexx.bridges import VexxLogitsProcessor

processor = VexxLogitsProcessor.from_spec(portfolio, tokenizer=tokenizer)
outputs = model.generate(**inputs, logits_processor=[processor])

# vLLM / SGLang expose a list of processors; llama.cpp may only accept GBNF
from vexx.bridges import patch_vllm
patch_vllm(engine, spec=portfolio, tokenizer=tokenizer)

# Providers you cannot constrain: verify post-hoc and raise on failure
from vexx.bridges import patch_openai
client = patch_openai(openai_client, spec=portfolio)`} copyable />

<Callout variant="warn" title="Verify the adapter">
GPU bridges are adapter-tested against fakes in this repository, not against live vendor servers. Read
the bridge page for your runtime and add an integration test before production traffic.
</Callout>

## Step 5 — inspect and certify

<CodeBlock language="bash" title="trace + certificate" code={`# render a standalone HTML trace report
python -m vexx inspect trace.json --out report.html

# verify a certificate offline; exits 0 only when every check passes
python -m vexx verify-proof proof.json`} copyable />

```python
certificate = vx.build_certificate(portfolio, report.values)
assert vx.verify_proof(certificate).ok
certificate.save("proof.json")

# bind verification to the spec you trust
assert vx.verify_proof("proof.json", expected_spec=portfolio).ok
```
