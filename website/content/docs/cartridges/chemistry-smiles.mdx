SMILES is a grammar with chemistry attached. A language model can produce a string that looks
plausible and is not a molecule. `chem` parses it: atoms, bonds (including ring closures and branches),
charges, implicit hydrogens, formula and molecular weight.

<Callout variant="warn" title="A verifier, not a chemical database">
The parser models the documented SMILES subset. It does not perform canonicalisation, tautomer
resolution or reaction mapping. Lowercase aromatic atoms are tokenised, but the valence model counts
the bond orders as written, so some fused aromatic systems are rejected rather than reinterpreted —
downstream chemistry still needs a cheminformatics toolkit.
</Callout>

<FeatureGrid>
  <Feature title="Real tokenisation" icon="database">
    Two-letter elements (`Cl`, `Br`), bracket atoms (`[NH4+]`), branches and ring digits are parsed, not
    pattern-matched.
  </Feature>
  <Feature title="Valence limits" icon="check">
    Every bond order counts toward the element's allowed valence; over-valent atoms become errors.
  </Feature>
  <Feature title="Formula + weight" icon="layers">
    Hill-order formula and molecular weight fall out of the parsed graph.
  </Feature>
  <Feature title="Honest failures" icon="shield">
    Unclosed rings, dangling bonds and unknown elements are reported as errors — never guessed.
  </Feature>
</FeatureGrid>

## Parse a molecule

<CodeBlock language="python" title="ethanol and caffeine" code={`from veritas.cartridges.chem import analyze_smiles, molecular_weight

ethanol = analyze_smiles("CCO")
print(ethanol.ok)                 # True
print(ethanol.formula)            # {'C': 2, 'H': 6, 'O': 1}
print(round(ethanol.molecular_weight(), 3))   # 46.069

urea = analyze_smiles("NC(=O)N")
print(urea.as_dict())
# {'ok': True, 'atoms': 4, 'bonds': 3, 'formal_charge': 0,
#  'formula': {'C': 1, 'H': 4, 'N': 2, 'O': 1}, 'molecular_weight': 60.056,
#  'errors': [], 'warnings': []}

cyclohexane = analyze_smiles("C1CCCCC1")     # a ring that closes
assert cyclohexane.ok and cyclohexane.formula == {"C": 6, "H": 12}

broken = analyze_smiles("CC1CC")             # ring opened but never closed
assert not broken.ok
print(broken.errors)   # ["unclosed ring closure(s): ['1']"]`} copyable />

## Fine-grained checks

<CodeBlock language="python" title="valence and charge" code={`from veritas.cartridges.chem import valence_ok, smiles_valence_ok, formal_charge_neutral

# carbon with four bonds is fine, five is not
assert valence_ok("C", 4)
assert not valence_ok("C", 5)

# charges participate in the allowed valence
assert valence_ok("N", 4, charge=1)

assert smiles_valence_ok("CCO")
assert formal_charge_neutral([0, 0, 0])
assert not formal_charge_neutral([1, -1])`} copyable />

## Wire it into a schema guard

<CodeBlock language="python" title="after verification, before the lab queue" code={`from veritas.cartridges.chem import analyze_smiles

report = molecule_spec.verify(candidate)
report.raise_if_failed()

analysis = analyze_smiles(candidate["smiles"])
if not analysis.ok:
    raise ValueError(f"invalid SMILES: {analysis.errors}")
if analysis.formal_charge != candidate["charge"]:
    raise ValueError("declared charge disagrees with the parsed molecule")

print(analysis.formula, analysis.molecular_weight())`} copyable />

Use the DSL for properties that must never be emitted — for example, a molecular-weight bound computed
during decoding with `vt.require(candidate.mw <= 500, tol=1e-3)`.

## Limits

- Supported SMILES subset only; stereochemistry markers are parsed but do not change checks.
- Molecular weight uses a fixed atomic-weight table; isotopes and unspecified elements return `None`.
- Formal charge is the sum over explicitly parsed atoms, not a resonance-weighted model.
- The parser is a safety gate for generated strings, not a replacement for RDKit in production cheminformatics.
