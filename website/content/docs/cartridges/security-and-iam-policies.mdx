An agent is a sequence of tool calls. `vexx.cartridges.sec` gives that sequence a state machine:
declared tools with preconditions and effects, budgets that cannot be overdrawn, facts that gate
capabilities, and finite-trace LTLf policies evaluated over the recorded trace.

## A guarded transfer

<CodeBlock language="python" title="declare, gate, execute" code={`from vexx.cartridges.sec import WorldState, PolicyViolation

state = WorldState()

state.declare_tool(
    "transfer",
    requires=["authenticated", "kyc_verified"],
    effects=["funds_moved"],
    cost=25.0,
    budget_key="usd",
    mutating=True,
)
state.set_budget("usd", 100.0)

print(state.can_call("transfer"))        # False — no facts yet

state.assert_fact("authenticated")
print(state.can_call("transfer"))        # False — KYC still missing

state.assert_fact("kyc_verified")
print(state.can_call("transfer"))        # True

snapshot = state.snapshot()
state.before_tool_call("transfer", {"amount": 40})
state.record_call("transfer", amount=40)
print(state.remaining("usd"))            # 75.0

state.restore(snapshot)
print(state.remaining("usd"))            # 100.0`} copyable />

<Callout variant="info" title="Facts are monotone unless you revoke them">
`assert_fact` adds; `revoke_fact` removes. A tool's `effects` describe what the trace will claim, which
is what the policy layer evaluates — declare them honestly.
</Callout>

## Policies over a trace

<CodeBlock language="python" title="LTLf helpers" code={`from vexx.cartridges.sec import WorldState, kyc_before, budget_never_exceeded, no_double_spend

state = WorldState()
state.add_policy(kyc_before("transfer", "verify_kyc"), name="kyc-first")
state.add_policy(budget_never_exceeded(), name="no-overdraft")
state.add_policy(no_double_spend(limit=1, tool="transfer"), name="single-transfer")

# run the agent loop ...
violations = state.validate(errors_only=True)
for violation in violations:
    print(violation.as_dict())

state.enforce()     # raises PolicyViolation on the first error`} copyable />

`require_response("trigger", "response")` expresses "every trigger must be followed by a response" —
useful for approval workflows and human-in-the-loop gates.

## Wiring into a verified tool

<CodeBlock language="python" title="verify the return value before the caller sees it" code={`import vexx as vx
from vexx.cartridges.sec import WorldState

state = WorldState()
state.declare_tool("transfer", requires=["authenticated"], mutating=True)
state.assert_fact("authenticated")

@vx.verified_tool(spec=transfer_spec, world_state=state)
def transfer(amount: float, to: str) -> dict:
    return {"amount": amount, "to": to, "status": "accepted"}`} copyable />

## Limits

- Policies are evaluated on the **recorded trace**, not on hypothetical futures. A policy cannot
  prevent a call it has not seen; `can_call` is the preventive gate.
- `mutating=True` is declarative metadata. The cartridge does not sandbox the tool.
- LTLf support covers the documented operators (`always`, `eventually`, `before`, `responds`,
  `at_most`, `never`) over finite traces.
- Snapshots copy facts, budgets and history; external side effects are yours to roll back.
