A model can write `P(A) = 0.6`, `P(B) = 0.7`, `P(A ∧ B) = 0.05` without noticing that the last number is
impossible. `stat` checks the arithmetic of probability: coherence, bounds, consistency and graphical
independence.

## Coherence checks

<CodeBlock language="python" title="probability, bounds and Bayes" code={`from veritas.cartridges.stat import (
    probability_simplex, frechet_ok, bayes_consistency, joint_table_valid,
)

assert probability_simplex([0.2, 0.3, 0.5])
assert not probability_simplex([0.2, 0.3, 0.6])
assert not probability_simplex([0.7, 0.4, -0.1])

assert frechet_ok(0.6, 0.7, 0.4)      # lower bound max(0, .6+.7-1) = .3
assert not frechet_ok(0.6, 0.7, 0.05)

assert bayes_consistency(0.5, 0.2, 0.25, 0.4)   # P(A|B)P(B) == P(B|A)P(A)
assert not bayes_consistency(0.5, 0.2, 0.9, 0.4)

assert joint_table_valid([[0.1, 0.2], [0.3, 0.4]])`} copyable />

## Covariance and independence

<CodeBlock language="python" title="PSD and d-separation" code={`from veritas.cartridges.stat import matrix_psd, covariance_psd, is_d_separated

assert matrix_psd([[1.0, 0.5], [0.5, 1.0]])
assert not matrix_psd([[1.0, 2.0], [2.0, 1.0]])     # negative eigenvalue
assert covariance_psd([0.04, 0.03, 0.01])           # eigenvalues must be >= 0

# DAG: A -> B, A -> C, B -> D, C -> D
graph = {"A": [], "B": ["A"], "C": ["A"], "D": ["B", "C"]}

assert is_d_separated(graph, "B", "C", {"A"})    # blocked by the common cause
assert not is_d_separated(graph, "B", "C", ())   # open path through the collider D
assert not is_d_separated(graph, "A", "D", ())   # ancestor -> connected`} copyable />

<Callout variant="warn" title="d-separation needs the right graph">
`is_d_separated` takes a DAG mapping each node to its **parents**. A conditioning set that opens a
collider (or its descendant) can connect variables that look independent. Pass the graph you actually
believe, not the one that makes the answer convenient.
</Callout>

## In a schema

Probability coherence is cheap to state symbolically and should be enforced during decoding:

<CodeBlock language="python" title="mask incoherent probabilities" code={`import veritas as vt

@vt.verified_schema()
def beliefs(b: Beliefs):
    vt.require(vt.forall(b.probs.values(), lambda p: (0.0 <= p) & (p <= 1.0)))
    vt.require(vt.sum(b.probs.values()) == 1.0, tol=1e-9)
    vt.derive(b.joint_ab == b.probs["A"] * b.probs["B"], tol=1e-9)`} copyable />

Then call `frechet_ok`, `bayes_consistency` or `is_d_separated` on the concrete result for the parts that
are easier to express as code.

## Limits

- Fréchet bounds cover two events; higher-order coherence needs the full joint.
- `bayes_consistency` checks the identity up to tolerance — it does not estimate parameters.
- `matrix_psd` is dense and cubic; use it for small covariance matrices, not large graphs.
- d-separation assumes a DAG and a correctly declared parent map; cycles are not detected.
