LLM most often gets wrong. Every function takes concrete values and returns a number, a bool or a
dataclass — nothing is deferred.

## Check a portfolio

<CodeBlock language="python" title="weights, risk and Sharpe from one call" code={`from veritas.cartridges.quant import (
    portfolio_weights_valid, portfolio_stats, concentration_ok, is_positive_semidefinite,
    covariance_matrix,
)

RETURNS = {"AAPL": 0.14, "MSFT": 0.13, "NVDA": 0.24}
COV = {
    ("AAPL", "AAPL"): 0.048, ("AAPL", "MSFT"): 0.031, ("AAPL", "NVDA"): 0.042,
    ("MSFT", "MSFT"): 0.039, ("MSFT", "NVDA"): 0.036, ("NVDA", "NVDA"): 0.095,
}
weights = {"AAPL": 0.40, "MSFT": 0.35, "NVDA": 0.25}

assert portfolio_weights_valid(weights, allowed={"AAPL", "MSFT", "NVDA"}, lo=0.05, hi=0.50)
assert concentration_ok(weights, max_weight=0.50)
assert is_positive_semidefinite(covariance_matrix(list(weights), COV))

stats = portfolio_stats(weights, RETURNS, COV, risk_free=0.04)
print(stats.as_dict())
# {'expected_return': 0.1615, 'volatility': 0.2044,
#  'sharpe_ratio': 0.5945, 'variance': 0.041775, 'risk_free': 0.04}`} copyable />

<Callout variant="info" title="Same numbers as the DSL">
`portfolio_stats` mirrors `vt.dot`, `vt.quad_form` and `vt.sqrt`, so a value you spliced during
decoding can be re-checked independently. The covariance map accepts either `(a, b)` tuples or nested
dicts; only one triangle is required.
</Callout>

## Options

<CodeBlock language="python" title="price, implied vol, no-arbitrage" code={`from veritas.cartridges.quant import black_scholes_call, implied_volatility, no_arbitrage_bounds

price = black_scholes_call(S=100, K=100, r=0.05, sigma=0.2, T=1.0)
print(round(price, 4))                       # 10.4506

iv = implied_volatility(price, S=100, K=100, r=0.05, T=1.0)
print(round(iv, 6))                          # 0.2

assert no_arbitrage_bounds(price, S=100, K=100, r=0.05, T=1.0)
assert not no_arbitrage_bounds(1.0, S=100, K=100, r=0.05, T=1.0)   # below intrinsic`} copyable />

`implied_volatility` uses bisection on a monotone price function and returns `None` when no root exists
— it never invents a number.

## Limits

- Covariance must be symmetric after construction; a negative variance raises `ValueError` rather than
  being clamped with a ridge.
- `implied_volatility` is bisection, not Newton: deterministic, bounded, `None` on failure.
- Accounting helpers check **identities**, not accounting standards. They are guards, not an audit.
- No function here is a substitute for in-decode constraints: use `vt.require` when a wrong value must
  never be emitted.
