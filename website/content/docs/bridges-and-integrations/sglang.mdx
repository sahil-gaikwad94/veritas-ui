SGLang exposes `logits_processor` on its engine and request objects. The Veritas adapter targets the
list form; it refuses to guess when the host shape differs.

## API

<KeyValueTable
  rows={[
    { key: 'SGLangLogitsProcessor(tokenizer=None, spec=None, ...)', value: 'subclass of VeritasLogitsProcessor' },
    { key: 'SGLangBridge(model=None, spec=None, tokenizer=None)', value: 'bridge object' },
    { key: 'bridge.sampling_params()', value: '{"logits_processor": [processor]}' },
    { key: 'patch_sglang(engine, spec=None, tokenizer=None)', value: 'appends the processor to the engine' },
  ]}
/>

<CodeBlock language="python" title="request-level wiring" code={`import sglang as sgl
from veritas.bridges import SGLangBridge

engine = sgl.Engine(model_path="meta-llama/Llama-3.1-8B-Instruct")
bridge = SGLangBridge(engine, spec=portfolio, tokenizer=engine.tokenizer)

state = engine.generate(
    prompt="produce a portfolio",
    sampling_params={"temperature": 0.7, "max_new_tokens": 512, **bridge.sampling_params()},
)
report = portfolio.verify(state["text"])
report.raise_if_failed()`} copyable />

## Patching

<CodeBlock language="python" code={`from veritas.bridges import patch_sglang

patch_sglang(engine, spec=portfolio, tokenizer=engine.tokenizer)
# engine.logits_processor now contains the Veritas processor`} copyable />

<Callout variant="warn" title="Raising is the default">
If `engine.logits_processor` is not a list, `patch()` raises `TypeError` instead of replacing the
attribute. Use `sampling_params()` when you want an explicit, version-tolerant path.
</Callout>

## Adapter status

Tested against fakes. SGLang's runtime API moves quickly; pin a version and assert that
`len(engine.logits_processor)` changed after patching. The final `spec.verify(...)` remains mandatory —
a mask prevents malformed tokens, not a malformed world.
