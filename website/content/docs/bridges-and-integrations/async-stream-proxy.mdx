Providers you cannot constrain still stream text. `AsyncStreamSupervisor` watches that stream, keeps the
prefix grammatical, and **withholds the last chunk** until the completed document verifies — so a
consumer never receives a complete-looking payload that is wrong.

<CodeBlock language="python" title="wrap an OpenAI-style stream" code={`import asyncio
from vexx.bridges import AsyncStreamSupervisor, StreamViolation

supervisor = AsyncStreamSupervisor(
    spec=portfolio,
    require_complete=True,
    on_violation=lambda violation: print("rejected:", violation, violation.kind),
)

async def consume(stream):
    async for chunk in supervisor.supervise(stream):
        yield chunk          # safe: grammar held, final chunk withheld

async def run(stream):
    try:
        async for chunk in consume(stream):
            render(chunk)
    except StreamViolation as exc:
        # kinds: "grammar", "incomplete", "instance", "aborted"
        await fail(exc, exc.report)`} copyable />

## Behaviour

| Stage | What happens |
| :--- | :--- |
| Each chunk | Extract text (raw string, SSE `data:` frame, or OpenAI/Anthropic delta) and feed the PDA |
| Invalid prefix | Raise `StreamViolation(kind="grammar")` immediately |
| Final chunk | Held back until the document is structurally complete |
| With a spec | Verify the completed text; raise `kind="instance"` on `FAIL` / `INCOMPLETE` |
| Incomplete end | Raise `kind="incomplete"` when `require_complete=True` |
| Callback | `on_violation` runs before the exception propagates; sync or async |

<Callout variant="warn" title="This detects, it does not prevent">
By the time a stream exists, the provider has already sampled the tokens. The supervisor protects your
consumer and telemetry — it cannot mask or splice. Use a logits-processor bridge when you control the
runtime.
</Callout>

## Adapter status

Extraction for OpenAI and Anthropic delta shapes is adapter-tested with fake clients, not live traffic.
If your provider changes its chunk schema, `_extract_text` may miss content and the supervisor will
report an incomplete stream rather than passing it silently.
