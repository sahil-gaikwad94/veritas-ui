# Async Stream Proxy

A black-box SSE supervisor that sits between your application and cloud LLM APIs (OpenAI, Anthropic, etc.) — adding Veritas verification to any streaming endpoint.

---

## Architecture

```
Your App → Async Stream Proxy → Cloud LLM API
                    ↓
            Veritas WASM Worker
            (0.23 ms PDA mask)
```

---

### How It Works

1. Your app sends a request to the proxy
2. Proxy forwards to the cloud LLM API
3. As tokens stream back, Veritas WASM worker masks invalid tokens
4. Only verified tokens reach your app
5. Zero server cost — verification runs in the browser via WASM
