Diffusion language models predict many positions at once and unmask them in an order chosen by
confidence. Vexx provides the two primitives that bridge needs — Gumbel-max sampling and a stable
unmask order — plus a small orchestration object.

<CodeBlock language="python" title="sample and choose a position" code={`from vexx.bridges import DiffusionBridge, gumbel_max_sample, unmask_order

# temperature 0 is deterministic argmax
token = gumbel_max_sample({"a": 0.1, "b": 2.0, "c": 0.4}, temperature=0)
assert token == "b"

order = unmask_order([0.2, 0.9, 0.5, 0.9])
print(order)     # [1, 3, 2, 0] — stable on ties

bridge = DiffusionBridge(spec=portfolio, seed=7)
position = bridge.step(
    token_logits=[[0.1, 2.0], [3.0, 0.1], [0.5, 0.5]],
    mask=[True, True, False],
)
print(position)  # 0 or 1 — the more confident masked position`} copyable />

<Callout variant="info" title="Seeded determinism">
`DiffusionBridge(seed=...)` owns a `random.Random` instance, so a run is reproducible given the same
logits. `gumbel_max_sample` also accepts an explicit `rng`.
</Callout>

## How the mask still applies

The sampling primitives do not enforce your spec. Apply the JSON mask to each position's logits before
sampling (set invalid entries to `-inf`) and verify the finished canvas once unmasked. Zero-DoF
splicing is autoregressive by nature; in diffusion you compute the derived field after its inputs are
decoded and re-mask the dependent positions.

## Status

This is an **experimental** bridge: the sampling and ordering primitives are tested, but there is no
end-to-end diffusion model integration in the test suite. Treat it as a reference implementation to
adapt, not a supported production path.
