Some requirements are about **order**, not values: KYC before a transfer, a response after a trigger, at
most one write. Linear Temporal Logic over finite traces (LTLf) expresses exactly that, and Veritas
evaluates it against the recorded trace.

<Callout variant="info" title="Evaluation, not masking">
Policies in this release are checked on a trace you already have — before a call (prospective) or after
a run (retrospective). They are not compiled into the token mask. Use `vt.require` for constraints that
must hold during decoding.
</Callout>

## Operators

<KeyValueTable
  rows={[
    { key: 'always(predicate)', value: 'predicate holds at every step' },
    { key: 'eventually(predicate)', value: 'predicate holds at some step' },
    { key: 'before(earlier, later)', value: 'no `later` without a preceding `earlier`' },
    { key: 'responds(trigger, response)', value: 'every trigger is followed by a response' },
    { key: 'at_most(name, limit)', value: 'event occurs no more than `limit` times' },
    { key: 'never(name)', value: 'event never occurs' },
    { key: 'occurred(name)', value: 'event occurred at least once' },
    { key: 'evaluate(formula, target)', value: 'bool — from veritas.ltlf, over a Trace or WorldState' },
  ]}
/>

There is no `X` (next) or `U` (until) operator, and no separate `globally` alias — `always` is the
global operator. The API is intentionally small.

## Direct evaluation

<CodeBlock language="python" title="build formulas, evaluate a trace" code={`from veritas import Trace, before, responds, at_most, never, occurred
from veritas.ltlf import evaluate

trace = Trace()
for name in ["request", "verify_kyc", "approve", "transfer"]:
    trace.append(name)

print(evaluate(before("verify_kyc", "transfer"), trace))   # True
print(evaluate(responds("request", "approve"), trace))     # True
print(evaluate(never("refund"), trace))                    # True
print(evaluate(at_most("transfer", 1), trace))              # True
print(evaluate(occurred("approve"), trace))                 # True

bad = Trace()
for name in ["transfer", "verify_kyc"]:
    bad.append(name)
print(evaluate(before("verify_kyc", "transfer"), bad))      # False`} copyable />

## Policies on a world state

<CodeBlock language="python" title="the agent surface" code={`from veritas.cartridges.sec import WorldState, kyc_before, no_double_spend

state = WorldState()
state.add_policy(kyc_before("transfer", "verify_kyc"), name="kyc-first")
state.add_policy(no_double_spend(limit=1), name="single-transfer")

state.assert_fact("verify_kyc")
state.record_call("transfer", amount=10)

state.enforce()                 # raises PolicyViolation on the first error
print(state.validate())         # list[PolicyViolation] — everything, not just the first`} copyable />

`before_tool_call(tool, kwargs)` performs a **prospective** check: it appends the call to a snapshot of
the trace, evaluates the policies, restores the snapshot, and raises if the call would violate a policy.
`enforce()` performs the same check after the fact.

## Scope

- Finite traces only — the trace ends where your agent loop ends.
- Predicates are names or plain booleans; there is no first-order quantification over data.
- A policy cannot prevent a call it has not seen; `WorldState.before_tool_call` is the preventive gate.
- `snapshot()` / `restore()` copy facts, budgets, events and history — external side effects are not
  rolled back.
