The Python engine is the reference. The Rust engine is a **port of the same layers** used as an
accelerator, and the WASM build brings the grammar and numeric primitives to the browser. Nothing here
is a second public API you must learn.

## `crates/vexx-py`

The extension module is named **`vexx_py`** and is loaded by `vexx.native`. Its `PdaHandle` and
top-level functions are implementation details; use the documented `vexx.native` wrappers instead of
importing them directly.

## `crates/vexx-wasm`

`wasm32-unknown-unknown` bindings for browser-side grammar work. Build with `wasm-pack` or the wasm cargo
target. The exported functions:

| Export | Signature | Notes |
| :--- | :--- | :--- |
| `version` | `() -> string` | Crate version |
| `prefix_status` | `(text) -> string` | Returns a **string**, not an object |
| `is_valid_document` | `(text) -> boolean` | Complete JSON only |
| `canonical_document` | `(text) -> string \| undefined` | Canonical rendering |
| `numeric_prefix` | `(text, lo, hi, allow_exp) -> Float64Array` | `[lo, hi]` bounds |
| `solve_linear_json` | `(json) -> string` | Linear solve result |
| `PdaHandle` | class | Incremental handle |
| `?` error shape | `{ status: "error", reason }` | Returned as a JSON string by mask helpers |

### `PdaHandle` (WASM)

```typescript
class PdaHandle {
  constructor();
  push(text: string): boolean;
  isAlive(): boolean;
  isComplete(): boolean;
  accepts(): boolean;
  depth(): number;
  maskJson(vocabularyJson: string, eos: string): string;
}
```

<CodeBlock language="typescript" title="browser usage" code={`import init, { PdaHandle, prefix_status, is_valid_document } from 'vexx-wasm';

await init();

const handle = new PdaHandle();
handle.push('{"w');
console.log(handle.depth(), handle.isAlive(), handle.accepts());

const mask = JSON.parse(handle.maskJson(JSON.stringify(['"a"', '1', '}', '']), ''));
console.log(prefix_status('{"w'));            // 'incomplete'
console.log(is_valid_document('{"a": 1}'));  // true`} copyable />

There is **no npm package** published for this build; vendor the generated `pkg/` directory or build it
in your pipeline.

## Kill switch

<CodeBlock language="bash" code={`VEXX_NO_NATIVE=1 python -m vexx doctor
VEXX_NO_NATIVE=1 python -m pytest tests/test_native_backend.py -q`} copyable />

Checked per call. The native path is preferred only when `vexx.native.available()` is true; every
wrapper falls back, and `tests/test_native_backend.py` pins the parity.

## What is and is not accelerated

| Accelerated | Stays in Python |
| :--- | :--- |
| Prefix classification, token masks | Full decode orchestration, telemetry, traces |
| Numeric prefix intervals, HC4 contraction | Schema compilation and Pydantic lowering |
| Linear feasibility, exact solves | Instance evaluation and derived fill |
| CDCL jumpback, zero-DoF splices | Certificates and SMT export orchestration |

Speedups quoted elsewhere (17.9× on `TokenMasker.valid_mask`, 1.5× on `Interval.from_numeric_prefix`)
come from `benchmarks/native_speedup.py` on a GitHub Actions runner. Measure your own workload before
promising anything.
