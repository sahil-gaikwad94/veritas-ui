# Rust Native & WASM Core

The Veritas engine is implemented in Rust across three crates. The core crate has **zero external dependencies** — it's pure, self-contained Rust.

---

## `crates/veritas-core` (15 Modules, Zero External Crates)

The core engine contains 15 modules, each responsible for a specific part of the pipeline:

| Module | Purpose | Lines |
| :--- | :--- | :--- |
| `pda.rs` | JSON Pushdown Automaton | ~400 |
| `json.rs` | JSON grammar & token masking | ~350 |
| `interval.rs` | Outward-rounded IEEE-754 intervals | ~300 |
| `num.rs` | Numeric utilities | ~200 |
| `expr.rs` | Symbolic expression trees | ~250 |
| `contractor.rs` | HC4 + AF2 interval contractors | ~450 |
| `nano_solver.rs` | Fourier-Motzkin linear solver | ~400 |
| `solver.rs` | Search & SAT solving | ~300 |
| `cdcl_jumpback.rs` | Conflict-driven jumpback | ~350 |
| `crane_mode.rs` | Dual-mode reasoning controller | ~250 |
| `zero_dof.rs` | Zero-DoF jump-forward splicing | ~300 |
| `token_healer.rs` | BPE token boundary healing | ~200 |
| `smt_bridge.rs` | Z3 SMT bridge | ~250 |
| `wire.rs` | Wire protocol serialization | ~200 |
| `lib.rs` | Crate root & public API | ~150 |

**Total: ~4,500 lines of dependency-free Rust**

## `crates/veritas-py` (PyO3 Bindings)

Python bindings that expose the Rust engine to Python. The main interface is `PdaHandle` and top-level convenience functions.

### `PdaHandle` API

| Method | Signature | Description |
| :--- | :--- | :--- |
| `new` | `(seed: str) -> PdaHandle` | Create a new PDA handle |
| `push` | `(token: str) -> bool` | Feed a token into the PDA |
| `is_alive` | `() -> bool` | PDA still in valid state |
| `is_complete` | `() -> bool` | JSON document complete |
| `accepts` | `(token: str) -> bool` | Token is syntactically valid next |
| `depth` | `() -> int` | Current stack depth |
| `last_event` | `() -> str` | Last PDA transition event |
| `candidates` | `() -> List[str]` | Top candidate next tokens |
| `mask` | `() -> List[float]` | Full logit mask tensor |
| `clone_handle` | `() -> PdaHandle` | Deep copy for speculative decoding |

### Top-Level Functions

| Function | Signature | Description |
| :--- | :--- | :--- |
| `prefix_status` | `(text: str) -> dict` | PDA status for a token prefix |
| `validate_document` | `(text: str) -> bool` | Validate a complete JSON document |
| `canonical_document` | `(text: str) -> str` | Canonical JSON form |
| `document_value` | `(text: str) -> Any` | Extract document value |
| `allowed_tokens` | `(text: str) -> List[str]` | Allowed next tokens |
| `numeric_prefix` | `(prefix: str) -> dict` | `[lo, hi, valid]` interval bounds |
| `contract` | `(spec_json: str) -> str` | Run interval contraction |
| `log_volume` | `(spec_json: str) -> float` | Log volume of feasible region |
| `solve_linear` | `(spec_json: str) -> dict` | Solve linear constraints |
| `solve_linear_exact` | `(spec_json: str) -> dict` | Exact linear solution |
| `engine_info` | `() -> dict` | Engine version & metadata |

### Example Usage

<CodeBlock language="python" code="from veritas._native import PdaHandle, prefix_status, engine_info

# Check engine info
info = engine_info()
print(info)
# {'version': '2.0.0', 'wire_protocol': '2.0', 'rust_core': True}

# Create PDA and check prefix status
handle = PdaHandle.new('{')
handle.push('\"')
handle.push('w')

status = prefix_status('{\"w')
print(status)
# {'valid': True, 'depth': 2, 'complete': False, 'allowed_tokens': [...]}`} copyable />

## `crates/veritas-wasm` (WebAssembly Bindings)

Browser-compatible WASM bindings for the client-side playground. Compiled with `wasm-pack build --target web`.

### JavaScript/TypeScript API

| Function | Signature | Description |
| :--- | :--- | :--- |
| `version` | `() => string` | Engine version string |
| `prefix_status` | `(text: string) => object` | PDA prefix status |
| `is_valid_document` | `(text: string) => boolean` | Document validity check |
| `PdaHandle` | class | Full PDA handle |

### `PdaHandle` Class (TypeScript)

```typescript
class PdaHandle {
  constructor(seed: string);
  push(token: string): boolean;
  isAlive(): boolean;
  isComplete(): boolean;
  accepts(token: string): boolean;
  depth(): number;
  lastEvent(): string;
  candidates(): string[];
  mask(): Float32Array;
  cloneHandle(): PdaHandle;
}
```

### Example Usage

<CodeBlock language="typescript" code="import { PdaHandle, prefix_status, is_valid_document, version } from 'veritas-wasm';

console.log(version()); // "2.0.0"

const handle = new PdaHandle("{");
handle.push('"');
handle.push('w');

console.log(handle.depth());      // 2
console.log(handle.isAlive());    // true
console.log(handle.accepts('e')); // true

const mask = handle.mask(); // Float32Array of logit mask
const status = prefix_status('{"w');
// { valid: true, depth: 2, complete: false, allowed_tokens: [...] }

console.log(is_valid_document('{"weights": {"AAPL": 0.40}}')); // true/false`} copyable />

## `VERITAS_NO_NATIVE=1`

Force pure-Python reference execution for A/B debugging and fault isolation testing.

<CodeBlock language="bash" code="# Force pure-Python engine
VERITAS_NO_NATIVE=1 python -m veritas doctor
# Engine: reference (pure Python)
# Native: disabled

# Normal mode (Rust native if available)
python -m veritas doctor
# Engine: accelerated (Rust native)
# Native: loaded`} copyable />

### When to Use

| Scenario | Setting |
| :--- | :--- |
| Production | Don't set (use Rust native) |
| Debugging native crashes | `VERITAS_NO_NATIVE=1` |
| Comparing Python vs. Rust results | Run both, compare |
| Environment without Rust compilation | `VERITAS_NO_NATIVE=1` |

<Callout variant="tip" title="Fault Isolation">

If a native Rust call ever panics, Veritas automatically falls back to the pure-Python reference engine. Your application never crashes — it just slows down temporarily (17.9x slower for PDA masking).

</Callout>
